feat(payments): add per-customer limit configuration
FEAT/PAYMENTS-RATELIMIT-CONFIG → FEAT/PAYMENTS-RATELIMIT-BUCKET · 07 FILES · 03 COMMITS

Introduces a per-customer rate-limit override on top of the global token-bucket configuration. Defaults remain unchanged; customers without an override hit the default RPS. Overrides carry an ExpiresAt so we can run temporary lifts (campaigns, partner ramps) without manual cleanup. Closes FEAT-2871.
